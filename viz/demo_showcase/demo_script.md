# 1분 데모 대본

핵심 메시지: 이미지 전체 패치를 다 어텐션하는 대신 물체 단위 슬롯 몇 개만 놓고 self/cross-attention을
한다 — 슬롯 수는 적지만 각 슬롯은 DINO 증류로 대형 비전 모델 수준의 의미 정보를 담고 있어서
정보 손실 없이 효율을 챙겼다는 것. 지금 당장의 실행은 policy가 아니라 좌표 + 저수준 제어(IK)로
하고, PPO 정책은 예측 가능한 범위 안에서 동작하도록 만든 뒤 향후에 붙일 계획이다.

## [0:00–0:08] 오프닝 — 핵심 인사이트 (효율)

"저희 파이프라인의 핵심은, 이미지 전체 패치를 다 어텐션하는 대신 물체 단위 슬롯 몇 개만 놓고
attention을 한다는 겁니다."

## [0:08–0:26] 지각 — 슬롯 압축 + DINO 증류 (perception.png)

"카메라 한 장에서 블록마다 위치, 방향, 색을 뽑아 슬롯 하나로 압축합니다. 이때 그냥 좌표만
담는 게 아니라, 메타의 DINO라는 대형 자기지도 비전 모델의 물체 특징을 슬롯이 그대로 재현하도록
학습시켜서, 슬롯 하나에 물체의 의미 정보까지 눌러 담았습니다. 그래서 토큰 수는 확 줄여도
정보는 줄지 않습니다."

## [0:26–0:42] 언어 이해 — 슬롯 attention (reasoning.png)

"'파란색 옆에 있는 거 줘'라고 말하면, 슬롯 서너 개끼리 self-attention으로 서로의 위치 관계를
파악하고, 명령어 토큰이 cross-attention으로 슬롯들을 훑어서 정답을 찾습니다. 패치 수백 개를
보는 것보다 훨씬 가볍고 빠르면서도, 여덟 가지 공간 관계에서 평균 94%를 맞춥니다."

## [0:42–0:56] 핵심 메시지 — 저수준 제어로 넘김

"그런데 진짜 강조하고 싶은 건 여기부터입니다. 이 좌표를 다시 '알아서 움직여'라는 policy에
맡기지 않고, IK 기반 저수준 제어기에 그대로 넘겨서 로봇 팔을 예측 가능하고 반복 가능하게
움직입니다 — 산업 현장에서 가장 신뢰할 수 있는 방식이기 때문입니다."

## [0:56–1:05] 클로징 — 향후 계획

"'어떻게 알아들었는지'는 슬롯 attention으로 효율적으로, '어떻게 움직이는지'는 산업 현장이
신뢰하는 고전 제어로 — 이 분리가 핵심이고, 앞으로는 이 좌표를 바탕으로 예측 가능한 범위
안에서만 동작하는 PPO 정책도 붙여볼 계획입니다."
